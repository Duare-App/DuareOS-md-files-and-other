## Page Template Pattern

Most pages can reuse this structure:

1. Hero: specific pain + product promise + CTA
2. Trust strip: logos, review score, number of locations, or local credibility
3. Problem section
4. Feature grid
5. Workflow screenshot / product UI section
6. Hardware or integration section when relevant
7. Industry-specific benefits
8. Customer quote / case study
9. FAQ
10. Final CTA
